## Bundled software

Web and Core builds generate `THIRD_PARTY_NOTICES.txt` from the modules actually
included by Vite. The Web collector also covers the separately bundled Worker,
the current Workbox precaching runtime and its installed dependencies, the
static notices above, and the Rust build dependency closure of the published
Brotli WASM release (`licenses/brotli-wasm.txt`). The supplement records the
exact upstream npm git commit, Cargo lockfile, crate versions and archive
checksums; this includes build-time crates and does not claim that all of them
are embedded in the binary. Updating `brotli-dec-wasm` requires refreshing this
version-checked supplement. All matching upstream LICENSE, COPYING,
and NOTICE files and copyright comments are retained; dual-license packages
keep both license texts. Package versions come from the installed packages.

The Web output contains `LICENSE.txt`; the standalone Core package contains
`LICENSE`. Both outputs include `THIRD_PARTY_NOTICES.txt`. These files must stay
with redistributed builds. The collector fails when an included npm package
has no license text instead of silently producing an incomplete notice.

Data and service attribution is documented separately in `docs/data-sources.md`.
